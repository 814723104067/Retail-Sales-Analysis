📊 Retail Sales Analysis using MySQL, Power BI & Tableau

Project Overview

  This project presents an end-to-end Retail Sales Analysis using MySQL, Power BI, and Tableau. The objective is to analyze retail sales data, identify business trends,       and create interactive dashboards that support data-driven decision making.

  The project demonstrates practical skills in SQL querying, business intelligence, dashboard development, and data visualization.

Objectives

  Analyze overall sales and profit performance.

  Identify top-performing categories and regions.

  Compare sales across customer segments and shipping modes.

  Visualize state-wise sales distribution using maps.

  Build interactive dashboards for business insights.

Tools & Technologies

  MySQL – Data querying and analysis

  Power BI – Interactive dashboard creation

  Tableau Public – Data visualization and dashboard design

  CSV Dataset – Sample Superstore retail dataset

Key Insights

  Technology category generated the highest sales.

  Certain states contributed significantly to overall revenue.

  Consumer segment represented the largest share of sales.

  Standard shipping mode was the most frequently used.

  Regional analysis highlighted variations in profitability.
